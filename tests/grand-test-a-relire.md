## 4. Contenus et mesures fragiles, décidés d'avance

| ID | Contenu | Précaution appliquée | Drapeau | Personne-date |
|---|---|---|---|---|
| CONT-01 | Indicateur d'impartialité (axe F) | Complet seulement, ≥ 8 décisions comparables, étiqueté « indicateur exploratoire » ; sinon démonstration sans note. Jamais de comparaison entre personnes | à relire | |
| CONT-02 | Vérité illusoire | **Jamais notée** : démonstration illustrative. Affirmations fausses exclusivement anodines (étymologie, géographie, faune) ; aucune fausse information de santé, de politique ni d'histoire sensible. Toutes corrigées après le rappel | à relire | |
| CONT-03 | DRM en français | Sans normes françaises publiées, chaque item porte `aRelire: true` et la démonstration n'est pas normative | à relire | |
| CONT-04 | Désinformation mémorielle | Consentement pédagogique annoncé, correction annoncée, aucun sujet traumatique ni politique, aucune note de mémoire si l'exposition peut nuire | à relire | |
| CONT-05 | Angle mort | Retour exploratoire seulement, sur quatre descriptions ; aucune fiabilité annoncée ; « écart d'auto-perception », jamais une déficience | à relire | |
| CONT-06 | Surestimation par étape | Aucun emploi de l'expression « effet Dunning-Kruger » sans mention des critiques statistiques (REF-20) ; un écart sur une passation n'est pas une caractéristique stable | à relire | |
