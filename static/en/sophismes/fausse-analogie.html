False analogy

Faulty analogy, Fausse analogie

Concluding that one thing has a property because it resembles another that has it, when the resemblance does not concern what matters.

The essentials

Argument diagram

A resembles B.

B has property P.

So A has property P.

Why the argument is invalid

An analogy can illuminate, but it proves nothing: it is valid only if the two things resemble each other precisely in the respect that produces the property. Superficial resemblances often hide decisive differences.

In practice

Example

“A state should be run like a household: it must never spend more than it earns.” Yet a state can levy taxes, borrow across generations and never retires.

Defending yourself

How to respond

Ask in what precise respect the two situations resemble each other, and whether that resemblance concerns what justifies the conclusion. Look for the important differences.

Don’t confuse

≠ Not to be confused with: False equivalence

A false analogy transfers a property from one thing to another; false equivalence asserts that two things are equal when they differ greatly in importance.

Going further

Source

The limits of reasoning by analogy have been discussed since Aristotle. David Hume, in the Dialogues Concerning Natural Religion (1779), criticises the analogy between the universe and a machine.
