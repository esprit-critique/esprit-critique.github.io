Politique de confidentialité

Mise à jour le 12 novembre 2026.

En bref : sans synchronisation, aucune donnée ne quitte votre navigateur. Si vous activez la synchronisation, une copie chiffrée de votre progression est gardée chez Cloudflare sous un identifiant dérivé de votre code : ce sont des données pseudonymisées, donc des données personnelles au sens du RGPD (détail plus bas). Pas de cookie, de mesure d'audience, de publicité ni de ressource extérieure (polices, scripts ou images d'autres sites). Si vous activez la synchronisation, une copie chiffrée sur votre appareil est conservée chez un hébergeur ; personne d'autre que vous ne peut la lire, pas même l'éditeur.

Ce qui reste dans votre navigateur

Votre progression est enregistrée dans le stockage local de votre navigateur (« localStorage ») : fiches acquises, réponses et révisions du quiz, résultats et niveaux des ateliers, prévisions et décisions que vous notez, repérages, fiches lues, parcours suivis, maîtrise, grade, points de lucidité et distinctions, objectif du jour, pseudonyme (facultatif) et réglages (thème, animations, mode sobre). Sans synchronisation, ces données ne quittent jamais votre appareil ; l'éditeur n'y a jamais accès. Elles servent uniquement au fonctionnement que vous demandez : ce stockage strictement nécessaire n'exige pas de consentement (article 82 de la loi Informatique et Libertés), d'où l'absence de bandeau.

Le site garde aussi, dans votre navigateur, jusqu'à quatre copies de cette progression : une par jour, et une juste avant un import ou une restauration. Elles permettent de revenir en arrière depuis Vos données.

Pour lire le site hors connexion, votre navigateur garde aussi une copie des fichiers du site (service worker). Elle ne contient aucune donnée vous concernant.

Vos droits sur ces données

Vous les exercez depuis le site, sans compte : l'éditeur ne peut ni lire votre copie en ligne ni la retrouver sans votre code.

  • Accès et portabilité : « Enregistrer dans un fichier », dans Vos données.
  • Suppression de la copie en ligne : « Supprimer la copie en ligne », dans Profil, Réglages (suppression immédiate sur le serveur).
  • Les effacer : « Effacer ma progression », au même endroit (les copies automatiques sont effacées aussi), ou en effaçant les données de navigation du site.
  • Les fichiers que le site crée (sauvegarde, agenda .ics) sont fabriqués sur votre appareil et ne sont envoyés nulle part.

Synchronisation (facultative)

Si vous l'activez (Profil, Réglages), votre progression est chiffrée dans votre navigateur (AES-256-GCM) avant d'être envoyée. Le serveur garde, pour chaque copie : un identifiant de 32 caractères dérivé de votre code, l'empreinte (SHA-256) d'un jeton lui aussi dérivé de votre code, le contenu chiffré (256 Ko au plus), un numéro de version, et les dates de création et de dernière écriture. Ni votre code, ni votre pseudonyme, ni votre adresse IP ne sont enregistrés dans cette base. Aucune adresse électronique, aucun nom, aucun mot de passe ne sont collectés ; le site ne peut pas récupérer un code perdu. Le code est gardé sur vos appareils connectés, pour pouvoir être réaffiché.

Ces éléments sont des données pseudonymisées : personne ne peut lire le contenu sans votre code, mais ils restent des données personnelles au sens du RGPD.

  • Base légale : votre consentement (article 6, paragraphe 1, a du RGPD). La synchronisation n'est activée que si vous le demandez ; vous retirez votre consentement en supprimant la copie en ligne.
  • Où : dans une base Cloudflare D1 créée avec la juridiction « Union européenne » (stockage dans l'Union).
  • Combien de temps : tant que vous l'utilisez ; une purge quotidienne supprime toute copie restée 24 mois sans écriture.
  • Sous-traitant : Cloudflare, Inc. (service Cloudflare Workers et base D1), selon son contrat de traitement des données. Comme tout hébergeur, Cloudflare voit l'adresse IP des requêtes, que le serveur du site n'enregistre pas.
  • Transfert hors de l'Union : Cloudflare est une société américaine, et les requêtes peuvent être traitées par ses centres de données hors de l'Union européenne. Ces transferts sont encadrés par la certification de Cloudflare au cadre de protection des données UE–États-Unis (Data Privacy Framework) et, à défaut, par les clauses contractuelles types de la Commission européenne (décision 2021/914).

L'hébergeur

Le site est hébergé par GitHub Pages. Comme tout hébergeur, GitHub reçoit les demandes de pages : selon sa documentation, l'adresse IP des visiteurs est enregistrée et conservée pour des raisons de sécurité. L'éditeur n'a pas accès à ces journaux. Voir la déclaration de confidentialité de GitHub.

Partage

Le bouton « Partager » ouvre le menu de partage de votre appareil, ou copie le lien : le site n'envoie rien lui-même. Les images « Partager cette carte » et « Partager mon grade » sont dessinées sur votre appareil, puis confiées au menu de partage ou enregistrées dans vos fichiers : elles ne passent par aucun serveur.

Installer le site comme une application (écran d'accueil) ne transmet rien non plus : votre appareil garde la page et ses fichiers.

Contact et réclamation

Pour toute question : tickets du dépôt (un compte GitHub est nécessaire ; vos droits, eux, s'exercent sans compte, depuis le site). Vous pouvez aussi adresser une réclamation à la CNIL (cnil.fr).
