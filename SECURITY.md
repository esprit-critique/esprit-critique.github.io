# Sécurité

## Signaler une faille

Utilisez le **signalement privé** de GitHub : onglet « Security » du dépôt, puis « Report a vulnerability »
(https://github.com/esprit-critique/esprit-critique.github.io/security/advisories/new). N'ouvrez pas d'issue publique.
Une réponse est donnée dans les meilleurs délais ; le site est tenu par une seule personne, bénévolement.

Le modèle de menace du site (ce qui est protégé, contre qui, comment, et les risques acceptés) est dans
[SECURITE.md](SECURITE.md). Adresse lisible par machine : https://esprit-critique.github.io/.well-known/security.txt

## Reporting a vulnerability

Please use GitHub private vulnerability reporting (link above), not a public issue.
